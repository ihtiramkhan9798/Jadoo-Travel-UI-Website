## ✨ Features

- **Hero Section** — Eye-catching landing area with travel-themed visuals and a search entry point.
- **Category Browsing** — Icon-based categories for exploring different types of trips and experiences.
- **Featured Destinations** — Showcases popular destinations (e.g. Europe, Greece, London, Rome) with imagery.
- **Newsletter Signup** — A dedicated section to capture visitor emails for updates.
- **App Download Section** — Promotes the mobile app with Apple Store and Play Store badges.
- **Fully Responsive Design** — Optimized for a clean experience across desktop, tablet, and mobile.

---

## 🛠️ Tech Stack

- **Structure:** HTML5
- **Styling:** CSS3 (with a dedicated responsive stylesheet)
- **Interactivity:** Vanilla JavaScript
- **Deployment:** [Vercel](https://vercel.com/)

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/ihtiramkhan9798/Jadoo-Travel-UI-Website.git
cd Jadoo-Travel-UI-Website
```

Since this is a static project with no build step, simply open `index.html` directly in your browser, or use a local server (e.g. the VS Code Live Server extension) for the best development experience.
